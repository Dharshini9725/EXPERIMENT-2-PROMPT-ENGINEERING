# EXP-2-PROMPT-ENGINEERING-

## Aim: 
Comparative Analysis of different types of Prompting patterns and explain with Various Test Scenarios

Experiment:
Test and compare how different pattern models respond to various prompts (broad or unstructured) versus basic prompts (clearer and more refined) across multiple scenarios. 
Analyze the quality, accuracy, and depth of the generated responses.


## Algorithm:

Here’s a well-structured, professional prompt you can directly use to generate your PDF report with images, including comparison across ChatGPT, Claude, and Gemini:
PROMPT:
You are an expert AI researcher and technical report writer. Your task is to generate a high-quality, professional PDF report titled:
“Comparative Analysis of Prompting Patterns Across AI Models”
📘 Report Requirements

* Format the output as a clean, well-designed PDF document
* Use clear headings, subheadings, and structured sections
* Include relevant diagrams/images/visual illustrations on each page
* Maintain formal academic tone
* Length: 7–10 pages
* Background: White with minimal, modern design
* Add tables, charts, and comparison visuals
📑 Content Structure
1. Introduction

* Define Prompt Engineering
* Importance of prompting in Generative AI
* Brief overview of AI models:
   * ChatGPT
   * Claude
   * Gemini
2. Types of Prompting Patterns
Explain each with examples:

* Zero-shot prompting
* Few-shot prompting
* Chain-of-thought prompting
* Role-based prompting
* Instruction-based prompting
* Open-ended vs structured prompts
👉 Include illustration diagrams showing prompt flow
3. Experiment Design

* Objective: Compare responses of different models
* Define test scenarios:
   * Broad / unstructured prompts
   * Clear / refined prompts
* Include:
   * Input prompt examples
   * Expected output criteria (accuracy, clarity, depth)
👉 Add flowchart of experimental setup
4. Test Scenarios and Outputs
Create at least 3–4 scenarios, such as:

* Scenario 1: General question (broad prompt)
* Scenario 2: Technical explanation (structured prompt)
* Scenario 3: Creative task
* Scenario 4: Problem-solving
For each scenario:

* Show:
   * Prompt used
   * Output from ChatGPT
   * Output from Claude
   * Output from Gemini
👉 Present results in table format
5. Comparative Analysis
Analyze based on:

* Accuracy
* Depth of explanation
* Creativity
* Response structure
* Context understanding
👉 Include:

* Comparison tables
* Bar charts / visual graphs
6. Key Observations

* Strengths and weaknesses of each model
* When to use which prompting style
7. Conclusion

* Summary of findings
* Importance of structured prompting
* Future improvements in prompting techniques
🎨 Design & Visual Requirements

* Add:
   * AI model comparison diagrams
   * Prompt-response flow visuals
   * Graphs comparing performance
* Use icons or illustrations for:
   * ChatGPT
   * Claude
   * Gemini
📊 Special Instructions

* Ensure outputs look realistic and comparable
* Maintain clarity and readability
* Use bullet points and tables where needed
* Make it suitable for academic submission or presentation
📄 Final Output

* Deliver as a downloadable PDF-style formatted document
* Ensure professional layout and formatting
